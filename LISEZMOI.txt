Mise en ligne

Le site est fait de pages HTML simples, sans serveur ni base de données.
Il suffit de déposer le contenu de ce dossier tel quel, en gardant les sous-dossiers css, js et img.

Sur GitHub Pages, déposer ces fichiers à la racine d'un dépôt, puis activer Pages dans les réglages du dépôt.
Pour la DSI, transmettre ce dossier complet.

Modifier une présentation dans css/usp.css la change sur toutes les pages en même temps.
